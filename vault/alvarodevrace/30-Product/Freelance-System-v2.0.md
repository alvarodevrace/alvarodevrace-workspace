# Freelance System v2.0

## Protocolos de Operación
- **A:** Cierre de contrato (Propuesta PDF -> Contrato Docuseal -> Pagos en Notion).
- **B:** Ejecución técnica.
- **C:** Facturación y Cobro (WF-ADR-02/05).
- **D:** Onboarding de Clientes (Linear project).
- **E:** Soporte (WF-ADR-03).
- **F:** Offboarding.

## Stack de Herramientas
- **Notion:** CRM, Pagos, Soporte (Fuente de Verdad).
- **n8n:** Orquestación y automatización.
- **Docuseal:** E-firma legal.
- **Gotenberg:** Generación de PDFs.
- **Telegram:** Notificaciones y alertas.
- **Resend:** SMTP transaccional.
