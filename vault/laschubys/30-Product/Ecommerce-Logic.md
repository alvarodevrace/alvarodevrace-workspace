# Ecommerce Logic — Las Chubys #negocio #tienda

Estrategia de monetización y flujo de venta.

## 🛍️ Modelos de Venta
1. **Venta Directa (Ecuador):**
   - Productos creados/gestionados por mamá (Iris/Rubi) desde el CMS.
   - Envío local.
   - Pago vía [[PayPhone]].
2. **Afiliación (Amazon):**
   - "Gatitos de Amazon" (Amazon Finds).
   - Botón redirige a Amazon con ID de afiliado.
   - Sin stock local ni gestión de envío.

## 🔄 Flujo de Usuario
- Landing → Tienda/Blog → Carrito (localStorage).
- Checkout → [[Auth]] Obligatoria → Pago (PayPhone) → Confirmación.
- Admin → Gestión de Blog y Stock Local.
